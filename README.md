# CuffsTycoon

광물을 캐서 수갑을 만들고, 범죄자에게 팔아 감옥을 채우는 하이퍼캐주얼 방치형 타이쿤입니다.

## 개요

| 항목 | 내용 |
|---|---|
| 장르 | 하이퍼캐주얼 방치형 타이쿤 |
| 개발 기간 | 2026.04.29 ~ 05.03 |
| 인원 | 1인 |
| 엔진 | Unity 6000.3.9f1 |
| 해상도 | 720 x 1280 (세로) |

## 게임 흐름

광산에서 광물을 캐고, 기계로 가공해 수갑을 만들고, 진열대까지 옮겨 손님에게 팝니다. 번 돈은 다시 업그레이드에 투자합니다. 채광, 가공, 운반, 판매를 진행하며, 감옥을 업그레이드합니다.

## 구현

### 업그레이드 영역

플레이어가 업그레이드 영역에 진입하면 애니메이션과 함께 재화를 지불하고, 다 모이면 해당 영역의 잠금이 해제됩니다. 영역의 업그레이드 진행도를 나타내기 위해 모인 자원만큼 영역을 채워 진행 상황이 눈에 보이도록 했습니다.

### NPC 구현

광부 NPC와 범죄자 NPC를 구현했습니다. 광부를 고용하면 플레이어 대신 채광을 시작해서, 캔 광물을 기계에 쌓고 곧장 다음 광물로 넘어갑니다. 범죄자는 가판대에서 수갑을 사면 그대로 감옥으로 들어갑니다.

### 업그레이드 테크트리

하나를 사야 다음 칸이 열리는 구조입니다. 채광 레벨을 올리면 광부 칸이 열리고, 광부를 들이면 그다음 손님 응대 칸이 열립니다. 무엇을 먼저 살지가 그대로 진행 속도를 좌우합니다.

### 오브젝트 재사용

들고 다니는 물건은 매번 만들고 없애지 않고, 미리 준비해둔 오브젝트를 개수만큼 켜고 끄는 식으로 표현했습니다. 인스펙터에 노출한 값에는 빠짐없이 설명을 달았고, 스크립트 안은 생명주기, 트리거, 코루틴처럼 기능 단위로 나눴습니다. 중복 실행을 막아야 하는 코루틴은 핸들을 하나만 쥐고, 다시 시작하기 전에 항상 먼저 멈췄습니다.
